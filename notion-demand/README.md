# Notion Demand Skill

Orchestrates Recipe Room demand work in the live Notion Product Roadmap and Tasks databases.

## Includes

- `SKILL.md`: operating router for Notion demand lifecycle work and schema discipline.
- `agents/openai.yaml`: agent configuration.
- `modes/`: detailed lifecycle mode files for Discovery, Design, Delivery, Launch, and Review stages.

## Use When

- Creating or shaping Recipe Room demand items.
- Updating demand lifecycle, stage, status, or linked task artefacts in Notion.
- Producing demand artefacts for requirements, UX, process, solution, technical design, delivery, QA, launch, or review.
- Keeping parent demand context and linked task work aligned without leaking scope between stages.
